What is recorded

While a session is active, this browser extension records the timing and type of your interactions with one website ([task website]): pointer movement and clicks, scrolling, touch, keyboard activity, focus changes, form submissions, and minimal page-element metadata (element tag, role, and a short selector hint).

  • Typed characters are not stored: keys are reduced to classes such as "letter" or "digit"; control keys such as Enter or Tab are kept.
  • On password fields and fields marked private, no key identity, key class, modifier state, or key timing detail is stored. The fact and time of each key event remain.
  • Page text, form values, clipboard contents, dragged data, file names, URL query strings and fragments, screenshots, audio, and video are not recorded.
