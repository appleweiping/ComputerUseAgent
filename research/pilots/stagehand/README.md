# Historical Stagehand supplemental smoke test

This directory documents the publication-safe Stagehand 3.7.1 integration smoke
completed on 2026-07-25. Its three successful public navigation tasks
(cost unreported) remain historical integration-pilot evidence, not MiniWoB
results and not a matched repeated-run benchmark. The sanitized records are in
`research/evidence/pilots/stagehand/`.

Stagehand was later retired because its reviewed production dependency graph
carried unresolved advisories. The original runner and dependency lock were not
published with this repository and nothing here can execute Stagehand; their
SHA-256 values are recorded in
[`research/week1_miniwob/adapters/archive/stagehand-3.7.1/README.md`](../../week1_miniwob/adapters/archive/stagehand-3.7.1/README.md).

The sanitized records exclude page bodies, raw model messages, browser profiles,
cookies, credentials and raw action traces. The detailed private evidence is not
published. No replacement framework is implemented.
