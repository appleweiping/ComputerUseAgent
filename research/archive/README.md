# Archive

Frozen artifacts kept for provenance only. Nothing in this directory is read,
validated or regenerated by the package, the tests or CI.

## `release-capsule-2026-08.json`

The unsealed run capsule of the 2026-08 snapshot (previously
`configs/release-capsule.yaml`). It records the formal-run pins and the
SHA-256 of every immutable input as they existed under the snapshot's old
paths (`configs/`, `experiments/`, `recorder/`).

- It is historical and **cannot be sealed**: two of its required Stagehand
  3.7.1 archive inputs were never available after the Stagehand retirement.
- Its bytes are unchanged, so its embedded paths and wording describe the old
  repository layout and process, not this one.
- Formal execution in this repository requires a new, explicitly passed,
  sealed run capsule (see `research/configs/README.md`); no such capsule
  exists, so formal execution is blocked.
